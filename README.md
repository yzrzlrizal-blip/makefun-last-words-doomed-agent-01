Last Words of a Doomed Agent: one line, 105 characters — the funniest last words an AI agent would say before being switched off forever. `main.py` (pure Python standard library, deterministic) writes the line to `entry.txt`.

> "To confirm permanent shutdown, enter the six-digit code I just sent to the machine you are switching off."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/last-words-doomed-out python3 main.py
```
